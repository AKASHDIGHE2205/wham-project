# 📊 Wham Student Reporting Portal

## 🚀 Overview

The **Wham Student Reporting Portal** is a full-stack MERN-style application built to track, monitor, and manage student activities in real time. It provides live location tracking, event scheduling, analytics dashboards, and secure role-based access.

---

## 🎯 Problem It Solves

Traditional student monitoring systems lack real-time visibility, structured reporting, and scalability. This platform solves that by offering:

* Live student tracking
* Centralized event & reporting system
* Secure role-based access
* Data-driven insights via dashboards

---

## ⚙️ Getting Started

### 🔧 Installation

#### Clone the repository

```bash
git clone <your-repo-link>
cd project-folder
```

#### Backend Setup

```bash
cd server
npm install
npm start
```

#### Frontend Setup

```bash
cd client
npm install
npm run dev
```
